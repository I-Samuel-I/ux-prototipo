# Ícones do protótipo

Origem: [biblioteca pessoal de Samuel Gomes](https://lib-icons-samuel.vercel.app/).

`samuel-icons.json` contém 45 SVGs distintos da variante Stroke / Rounded, com as formas originais do catálogo. O componente `src/components/icons.jsx` renderiza essas formas como elementos React e fornece os 49 nomes semânticos utilizados pela interface. Tamanho, cor e espessura podem ser ajustados pelas propriedades `size`, `color` e `strokeWidth`.

Os dados foram extraídos do catálogo público da biblioteca e incluídos no projeto. Não há requisição externa para carregar ícones em produção. O SVG de `briefcase` foi comparado com a prévia publicada e coincide com a origem. Os nomes abaixo apontam para as páginas dos respectivos SVGs.
